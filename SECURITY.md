# Security

Please don't report security problems in a public issue. Contact the maintainer on
Telegram: https://t.me/baha_kabulov with what you found and how to reproduce it.

Keep in mind how Apk on Mac works: an Android app running under Apk on Mac is ordinary
native code with your macOS user account's permissions. There is no phone-style
sandbox around it, so "an APK can read my files" is expected behaviour, not a bug.
Only install APKs you trust.
