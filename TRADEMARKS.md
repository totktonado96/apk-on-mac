# The Mac.apk name and logo

"Mac.apk" and the Mac.apk logo identify the official project and the builds published
on this repository's Releases page. The code licenses (AGPL-3.0, or a commercial
license) do not grant any right to use them.

You are welcome to fork Mac.apk. If you publish a fork or your own build:

- give it a different name and icon, so nobody mistakes it for the official app;
- you may say it is "based on Mac.apk" and link back here;
- don't present it as an official Mac.apk release, or imply it is endorsed by the
  project.

Writing about Mac.apk, linking to it, and using the name to refer to the official
project (in articles, videos, reviews or compatibility reports) is fine and doesn't
need permission.
